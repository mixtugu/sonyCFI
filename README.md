# 사이의 길 · Between Paths

**Cloudflare Workers 배포:** https://sony-cfi-between-paths.timmy0079.workers.dev

공개 주소에서 일본어 미로 게임을 2명이 동시에 플레이할 수 있습니다. 재배포는 `npm run deploy`, Workers 로컬 실행은 `npm run worker:dev`입니다. 자세한 내용은 [WORKERS.md](WORKERS.md)를 참고하세요.

기본 게임을 `test_coding`의 파이썬 게임을 참고한 **부모·아이 두 시점의 미로 게임**으로 개편했습니다. `npm run dev` 실행 후 `http://localhost:5173`에서 바로 플레이할 수 있습니다. 부모/아이/CPU 모드, 벽과 비밀 통로, 점수, 미로·시간·아이템 설정을 지원합니다.

새 미로도 **두 사람이 각자 브라우저에서 동시에 플레이**할 수 있습니다. 화면 위에서 방을 만들고 초대 링크 또는 코드를 공유한 뒤, 두 사람 모두 준비 완료를 누르세요. 부모는 벽을 설치하고 아이는 이동하며, 역할별 화면과 비밀 통로가 분리됩니다. 방에 들어가지 않으면 CPU와 혼자 연습할 수 있습니다.

새 게임의 조작법과 검증 방법은 [MAZE.md](MAZE.md)를 참고하세요. 기존 온라인 게임은 `/?online=1`과 기존 초대 링크에서 이용할 수 있습니다. 아래 내용은 기존 온라인 모드의 안내입니다.

# ふたりのあいだの海 · Between Tides

別々のブラウザーで同じ部屋に入り、子どもは泳ぎ、親はリアルタイムに壁を置く2人用ゲームです。画面、目標、地図の情報、操作を役割ごとに分けています。UIは日本語です。

## 起動

Node.js 20.19+ または 22.12+ を使用します。

```sh
npm install
npm run dev
```

PCで `http://localhost:5173` を開きます。一人が役割を選んで部屋を作成し、もう一人は別のブラウザー・端末から6文字のルームコード、または招待リンクで参加してください。二人の準備がそろうと3秒のカウントダウン後に開始します。

同じWi-Fiのスマホ・PCから接続する場合は、起動時に表示される `http://<PCのLANアドレス>:5173` を開きます。localhostで部屋を作ると、開発サーバーが検出したLANアドレスを招待リンクに設定します。複数のネットワークアダプターがある場合は起動ログから実際に共有しているネットワークのアドレスを選んでください。ルームコードだけでは異なるサーバー同士を接続できません。

Windowsから別端末で接続できない場合は、端末が同じネットワークにいるか、Node.jsのローカルサーバーがプライベートネットワークのファイアウォールで許可されているかを確認します。OS設定は本プロジェクトでは変更していません。

## 役割ごとの画面

| | 子ども：小さな探検家 | 親：海の見守り手 |
| --- | --- | --- |
| 自分だけの目標 | 真珠を5つ集めて東の光の門へ | 子どもを西の入り江に合計25秒とどめる |
| 自分に見えるもの | 真珠、光の門、自分の進捗 | 静かな入り江、滞在時間 |
| 共通で見えるもの | 探検家、置かれた壁、残り時間 | 探検家、置かれた壁、残り時間 |
| 操作 | WASD・矢印・画面のジョイスティック | ドラッグで壁、クリックで既定の壁。WASD・矢印・IJKLで照準、Spaceで設置、Rで回転 |
| ゲームパッド | 自分の端末の1台目：左スティック | 自分の端末の1台目：左スティック、A／×で設置、X／□で回転 |

親は子どものキャラクターを直接動かせません。子どもは壁を置けません。この制限はUIだけでなくサーバー側でも検証します。相手のミッション・進捗・専用地図は、終了前にその相手以外のソケットへ送りません。

タッチ端末では、親もジョイスティックで照準を動かし「壁を置く」ボタンで操作できます。ゲームパッドは標準マッピングを使用し、localhostまたはHTTPSで利用します。LAN上のHTTP接続ではタッチ／キーボードを使用してください。実機パッドの機種別確認は未実施です。

## ルールと振り返り

- 90秒間の航海。子どもが目標を達成すると、その時点で終了します。
- 壁は最長180ワールド座標、12秒間持続、最大5つ。0.65秒に一度置けます。6つ目を置くと最も古い壁が消えます。
- 子どもの体の上には壁を置けません。壁に接すると移動が止まり、迂回するか1.4秒押し続けると乗り越えられます。
- Esc／「ひと休み」で双方が一時停止します。タブを非表示にした場合も停止します。
- 切断を検出すると双方を停止します。再読み込み・一時的な切断後は同じ画面のセッショントークンで同じ役割に復帰し、二人の準備で再開します。移動入力は250msで失効するため、通信が止まっても泳ぎ続けません。
- 「ここまでの航海を振り返る」を一時停止中に選ぶと両画面で終了します。目標、実際の移動軌跡、壁の履歴、壁の前にいた時間を公開します。
- リプレイスライダーは各自の画面で自由に操作できます。役割交代には二人の同意が必要です。同じ接続を保ったまま役割と操作が切り替わります。

数値はゲームの初期バランスです。良い親・良い子を評価する指標ではなく、相手の意図について話すきっかけとして使用します。

## 接続の仕組み

- `server/index.js`：HTTPとWebSocketを同一ポートで提供。開発時はVite middleware、本番は`dist`を配信します。
- `server/rooms.js`：部屋、役割別トークン、参加人数、準備、再接続、情報の出し分けを管理します。
- `src/game.js`：移動・壁・衝突・タイマーをサーバーで30Hz計算します。クライアントは入力だけを送り、受信位置を補間して描画します。
- `src/main.js`：日本語UI、ルーム接続、各端末の入力、回復処理。
- `src/renderer.js`：役割ごとのCanvas描画、記録のリプレイ。

部屋と履歴はサーバーのメモリーに保存します。サーバー再起動では消えます。二人とも切断して2分が経つと部屋を削除します。アカウント、永続保存、観戦モードはありません。人数は各部屋2人です。

## 本番起動・別のネットワークからの接続

```sh
npm run build
npm start
```

`npm run preview`も同じ本番サーバーを起動します。ポートは環境変数`PORT`で変更できます。

別々のWi-Fiやインターネット越しに遊ぶには、Node.jsを実行できるホストへ配置し、HTTPSと`/socket`のWebSocket Upgradeを転送してください。静的ファイルだけの配信では部屋を接続できません。現時点で外部へのデプロイは行っていません。複数サーバー間での部屋共有も未実装です。

## 検証

```sh
npm test
npm run build
```

ゲームの衝突・移動・終了に加えて、役割制限、非公開情報の分離、二人の準備、切断・復帰、役割交代、実際のWebSocket通信を検証します。

開発サーバーの起動後に、独立したブラウザー同士のシナリオを実行します。

```sh
npx playwright install chromium
node scripts/check-browser.mjs
```

部屋参加、3人目の拒否、位置と壁の同期、再読み込みによる復帰、各端末の仮想ゲームパッド、共有の振り返り、役割交代、スマホのタッチ操作を確認します。スクリーンショットは`artifacts/*-ja.png`に保存します。

ゲームパッド参考：[MDN Gamepad API](https://developer.mozilla.org/en-US/docs/Web/API/Gamepad_API/Using_the_Gamepad_API)。サーバー参考：[ws](https://github.com/websockets/ws)、[Vite middleware mode](https://vite.dev/config/server-options#server-middlewaremode)。
