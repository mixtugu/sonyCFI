# 사이의 길 · Between Paths

`test_coding_20260830/test.py`의 파이썬 프로토타입을 참고해 기본 게임을 부모·아이 두 시점의 미로 실험으로 개편했습니다. 두 사람이 각자 브라우저에서 같은 미로를 동시에 플레이할 수 있습니다.

## 실행

```sh
npm install
npm run dev
```

`http://localhost:5173`을 엽니다. 배포용 실행은 `npm run build` 후 `npm start`입니다.

경로는 두 가지입니다.

| 경로 | 화면 |
| --- | --- |
| `/` | 방 설정 → 방 입장. 두 사람이 함께 플레이하는 기본 화면 |
| `/test` | CPU가 들어간 테스트 모드 (1인) |

## 플레이

도감은 종류별 12칸입니다. 참고 이미지 순서로 대형 3열(상어·인어·대왕오징어), 중형 4열(바다거북·문어·쏠배감펭·나비고기), 소형 5열(흰동가리·새우·해파리·해마·쑤기미)로 표시합니다. 대형 그림은 더 크게 표시합니다. 미발견은 어두운 실루엣과 `？？？`, 발견 후에는 컬러 그림과 이름이 나옵니다. 중복 생물은 같은 칸을 사용하며 종류 수는 중복 계산하지 않습니다. 결과의 만남 수는 접촉한 장소 수로 별도 표시합니다.

### 두 사람이 함께 플레이 (기본 화면)

`/`로 접속하면 **방 설정 화면**이 먼저 열립니다. 방에 들어가면 화면이 게임 보드로 바뀝니다.

1. 필요하면 **⚙ 미로 설정**으로 크기·시간·벽 수를 바꾼 뒤 **방 만들기**를 누릅니다.
2. 상대에게 초대 링크를 전달합니다. 상대는 링크를 열고 방 설정 화면에서 **참가**를 누릅니다. 참가 키는 항상 `A`입니다. 고정 키를 사용하므로 한 번에 하나의 방만 만들 수 있습니다.
3. 방을 만들거나 참가하면 전체 화면의 **대기·튜토리얼**이 열립니다. 각자 3단계 튜토리얼을 끝까지 확인하고, 대기 화면에서 **준비 완료**를 누릅니다. 두 사람 모두 확인·준비를 마치면 동기화된 **3 → 2 → 1** 카운트다운 후 시작합니다. 카운트다운 중에는 산소·시간이 줄지 않고 이동·벽 설치도 적용되지 않습니다.

한 판은 **2라운드**입니다. 방을 만든 사람이 부모, 참가한 사람이 아이로 1라운드를 하고, 2라운드에서 반드시 교대합니다. 각자 부모 한 번·아이 한 번을 하면 한 판이 끝납니다. 역할을 고르는 선택지는 없습니다.

- 1라운드가 끝나면 결과 창 없이 **자동으로 역할을 교대**하고, 새 역할의 튜토리얼을 엽니다. 두 사람 모두 다시 확인·준비를 마쳐야 **3 → 2 → 1** 카운트다운 후 2라운드가 시작합니다.
- 2라운드가 끝나면 **사람별 HP·도감 기록**(당신 / 상대)와 라운드별 결과를 보여줍니다. 각 사람이 내비게이터였을 때의 HP와 익스플로러였을 때의 도감 등록 수를 따로 표시하며 합산 점수는 없습니다. `終了する`를 누르면 수면으로 돌아오는 종료 연출 후 로비로 복귀합니다. 한 사람이 먼저 나가도 상대의 결과 화면은 유지됩니다. 두 사람이 모두 `한 번 더 놀기`를 선택하면 처음 자리(방장=부모)에서 새 판의 튜토리얼부터 시작합니다.

준비 팝업에는 라운드마다 **직접 움직여보는 3단계 튜토리얼**이 들어갑니다. 게임과 같은 렌더러를 사용하는 5×4 연습 미로가 팝업 안에 있어, 여기서 해본 조작이 본 게임과 똑같이 동작합니다.

튜토리얼이 열려 있는 동안은 팝업 전체가 브리핑입니다: 위에 역할·라운드 표시와 `閉じる`, 3칸 진행 바, 왼쪽 정사각형 그림(연습 판), 오른쪽에 `01 / 03`·제목·설명 한 줄·조작 키 줄, 아래에 `戻る`/`次へ`. 역할마다 단계가 다릅니다.

| 단계 | 부모 | 아이 |
| --- | --- | --- |
| 1 | 벽을 세워 익스플로러를 지키기 — 5×4 연습 판에서 방향키로 위치, Tab(○)으로 방향, Space(×)로 벽 설치 | 물고기에 닿아 도감 등록 — 연습 판에서 방향키로 한 칸씩 이동 |
| 2 | 물고기 접촉과 벽 설치로 내비게이터 HP 감소 (그림) | 벽을 피해 점선 비밀 통로 통과 — 연습 판 |
| 3 | 제한 시간 (그림, 설정한 초 표시) | 같음 |

누른 키는 조작 키 줄에서 잠깐 강조되고, 결과는 연습 판 아래 한 줄로 나옵니다. 터치에서는 칸을 탭하고 Tab/Space 키 표시를 탭합니다. Enter·`次へ`로 넘어가고, 마지막 단계의 `確認して待機へ`(또는 Enter)로 확인을 마친 뒤 별도의 `準備完了`를 누릅니다. `閉じる`/Esc로 일찍 닫아도 확인 처리되지는 않으며, `チュートリアルを確認`으로 다시 열 수 있습니다. 설정에서 바꾼 제한 시간이 3단계에 반영되고, 일시정지에서 재개할 때는 튜토리얼을 생략합니다. 게임패드로는 스틱·방향키로 연습 이동, ○ 방향 전환, × 벽 설치, OPTIONS로 다음 단계·준비 완료입니다.

준비 팝업에는 그 밖에 자기 역할, 상대 접속 상태, 상대를 기다리는 동안의 방 코드·초대 링크 복사, 그리고 ⚙ 설정이 함께 있습니다. 일시정지에서 재개할 때도 같은 팝업이 뜹니다. 방에 들어가면 툴바에도 방 코드와 상대 상태가 표시됩니다.

같은 Wi-Fi의 다른 기기에서는 `localhost` 대신 서버 PC의 LAN 주소를 사용합니다. 로컬에서 복사하는 초대 링크는 LAN 주소로 구성되며, 터미널에도 주소가 표시됩니다. 다른 네트워크에서 플레이하려면 두 브라우저가 접근할 수 있는 서버에 배포해야 합니다.

라운드마다 내비게이터 HP 30 / 도감 0개에서 새로 시작합니다. 같은 장소의 물고기에 다시 닿아도 HP 감소나 등록이 중복되지 않습니다. 첫 라운드 준비 중 설정을 바꾸면 확인·준비 상태가 초기화됩니다. 최종 결과 이전에 누군가 나가면 1라운드부터 다시 시작하며, 최종 결과는 상대가 나가도 보존됩니다.

각 화면은 맡은 역할의 미로만 표시합니다. 비밀 통로는 익스플로러에게만, HP와 접촉한 물고기의 데미지는 내비게이터에게만 전달됩니다. 도감 등록 상태는 공유되며, 화면의 도감은 익스플로러에게 표시합니다. 결과에서는 두 사람의 HP와 도감을 확인할 수 있습니다. 한 명이 일시정지하거나 연결이 끊기면 둘 다 멈춥니다. 새로고침하면 참여 정보를 복원하고, 두 사람이 준비하면 3초 카운트다운 후 이어집니다. 결과에서 두 사람 모두 다음으로 진행하면 새 미로로 돌아갑니다.

방장은 첫 라운드 시작 준비 중 설정을 변경할 수 있습니다. 두 번째 라운드에서는 설정을 변경할 수 없습니다. 변경하면 두 사람의 준비 상태도 초기화됩니다. 방에서 나가면 상대는 새로운 참가자를 초대할 수 있습니다. 서버 메모리에 방을 보관하므로 서버 재시작 시 방은 사라집니다.

### 테스트 모드 `/test`

CPU가 들어간 1인 연습·확인용 모드입니다. `/test`로 접속하거나 방 설정 화면 아래의 링크를 누르면 열립니다. 네트워크에 연결하지 않고 선택한 역할의 화면만 표시합니다. 내비게이터 선택 시 내비게이터 미로와 HP, 익스플로러 선택 시 익스플로러 미로와 도감을 표시합니다. HP·도감은 데스크톱에서 미로 오른쪽의 큰 패널에 표시하며, CPU 관찰 모드만 두 역할을 함께 보여줍니다. 역할 교대 시에도 새 역할의 화면만 표시합니다.

- 부모 플레이: 아이 CPU는 가까운 미지 아이템으로 이동합니다. 부모는 미로의 빈 통로에 벽을 설치합니다.
- 아이 플레이: 방향키/WASD 또는 화면 버튼으로 아이를 움직입니다. 부모 CPU가 주변 통로에 벽을 설치합니다.
- CPU 관찰: 양쪽 모두 자동으로 진행합니다. 진행 중 모드를 바꿀 수 있습니다.
- 부모의 커서는 방향키/WASD로 이동합니다. 미로에 포커스를 둔 상태에서 Tab으로 벽 방향을 바꾸고 Space로 설치합니다. 미로 칸의 가장자리 클릭도 지원합니다.
- 전체화면: 툴바의 ⛶ 버튼, F 키, 컨트롤러 △. 미로·HP·도감·산소통·시작 버튼과 ⚙ 설정 버튼만 남기고 나머지 UI는 숨깁니다. Esc 또는 ✕로 종료합니다. 터치 기기에서는 방향 버튼을 유지합니다.
- 설정: 툴바의 ⚙ 버튼, 컨트롤러 □. 미로 설정과 방 정보(코드·초대 링크·퇴장)를 한 창에서 다룹니다. 전체화면에서도 그대로 열립니다. 창을 열면 진행 중인 라운드는 일시정지합니다.
- 교대: 라운드가 끝나면 다음 라운드는 반드시 역할을 바꿔서 시작합니다. 결과 창의 **교대해서 한 번 더**나 시작 버튼을 누르면 부모였던 쪽이 아이가 됩니다. CPU 관찰 모드는 교대하지 않습니다.
- PS5(DualSense) 등 게임패드: 방향키/왼쪽 스틱으로 이동·커서 선택, × 벽 설치, 오른쪽 스틱으로 벽 방향 지정(기울인 쪽), ○ 벽 방향 회전, OPTIONS 시작/일시정지, CREATE 리셋, L1/R1 모드 전환, □ 설정, △ 전체화면. 결과·도움말 창에서는 × 확인, ○ 닫기. 벽 설치·아이템 획득·라운드 종료 시 진동합니다. 브라우저 보안상 연결 후 버튼을 한 번 눌러야 인식됩니다. 검증: `node scripts/check-gamepad.mjs`
- 시작 버튼은 진행 중 일시정지, 정지 중 재개 버튼으로 바뀝니다. Esc, 창의 포커스 상실, 다른 탭으로 전환할 때도 일시정지합니다.

점수 제도와 보상·벽 비용 설정을 제거했습니다. 물고기에 닿으면 도감의 대응 슬롯이 채워지고, 실제로 나타난 생물의 위험도에 따라 내비게이터 HP가 낮음 2 / 중간 3 / 높음 4 감소합니다. 최대 위험도별 실루엣은 각 4개이며, 총 데미지는 최대 36으로 HP가 0이 될 수 있습니다. 벽은 기본 10개이며 설치 성공 시 HP를 2 소모하고, 실패 시에는 소모하지 않습니다. 도감은 줄어들지 않습니다. HP는 0 미만이 되지 않으며, 0에서도 시간 종료까지 이동·도감 등록·벽 설치를 계속할 수 있습니다.

내비게이터의 HP 하트는 한 줄에 10개씩 두 줄로 표시합니다. 그 아래에는 남은 벽 수와 벽 아이콘을 표시하며, 설치한 벽은 흐리게 바뀝니다. 벽 개수 설정과 라운드 초기화에도 남은 수가 연동됩니다.

미로의 물고기는 같은 청록색 발광 윤곽선으로 그리며 대·중·소 크기를 유지합니다. 내비게이터에게만 최대 위험도 낮음 `!` / 중간 `!!` / 높음 `!!!`를 같은 색으로 표시합니다. 같은 크기에서 최대 위험도 이하인 생물 중 무작위로 나타나며, 높은 위험도 표시에서 더 안전한 생물이 나올 수 있습니다. 접촉 후 미로와 도감에는 원본 일러스트의 파란 배경을 제거한 투명 PNG 12종을 표시합니다. 단순화한 SVG는 사용하지 않으며, 접촉 전 실루엣은 유지합니다. 대형은 상어·인어·대왕오징어(모두 높음)라서 `!!!`에만 배치합니다. 중형은 바다거북·나비고기(낮음), 문어(중간), 쏠배감펭(높음), 소형은 흰동가리·새우·해마(낮음), 해파리(중간), 쑤기미(높음)입니다. 익스플로러에게 접촉 전 위험도와 생물 종류는 전달하지 않습니다. 추첨은 시드로 고정되어 재접속·초기화로 바뀌지 않으며, 다른 장소에서 같은 생물이 나와도 도감의 같은 칸을 사용합니다.

벽이 아이의 접근 영역을 제한하면 아이만 지날 수 있는 비밀 통로가 생성되어 모든 칸에 도달할 수 있습니다. 아이 시점의 청록 점선이 비밀 통로입니다. 부모 시점의 깃발은 표식이며 시간 종료가 라운드 종료 조건입니다.

기본값은 14×10 미로, 30초, 벽 12개, 500ms 이동 간격입니다. 설정 적용은 새 미로를 만들고 게임을 초기화합니다. 초기화 버튼은 같은 미로·아이템 배치로 돌아가며, 기본 설정 버튼은 최초 실험으로 되돌립니다. 파이썬과 같은 난수 구현을 사용하지 않으므로 미로와 아이템 배치는 동일하지 않습니다.

방에 참여하지 않은 상태에서는 한 기기에서 두 시점을 함께 보는 연습 모드를 사용할 수 있습니다.

## 구현과 검증

- `src/entry.js`: 새 기본 게임 / 기존 온라인 게임 진입 분기
- `server/maze-rooms.js`, `src/maze-network.js`: 미로 2인 방, 역할별 상태 전송, 재접속, 준비 및 재시작 동기화 (`/maze-socket`)
- `src/maze.js`: 재현 가능한 미로 생성, 이동, BFS 경로 탐색, 벽, 비밀 통로, CPU, HP·도감
- `src/tutorial.js`: 준비 팝업의 3단계 연습 튜토리얼 (조작 → HP/비밀 통로 → 시간). 게임 렌더러로 그리는 연습 미로
- `src/maze-main.js`, `src/maze-renderer.js`, `src/maze.css`: 한국어 UI, Canvas 두 시점, 모바일 조작, 설정, 기록과 결과

```sh
npm test
npm run build
node scripts/check-maze.mjs
node scripts/check-maze-network.mjs
```

브라우저 검증에는 Playwright Chromium이 필요합니다 (`npx playwright install chromium`). 검증 스크립트는 임시 포트에서 빌드 결과를 실행한 뒤 종료하며 데스크톱·모바일·결과 화면을 `artifacts/maze-*.png`에 저장합니다.
