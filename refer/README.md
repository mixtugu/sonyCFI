# 사이의 길 · Between Paths

**Cloudflare Workers 배포:** https://sony-cfi-between-paths.timmy0079.workers.dev

공개 주소에서 일본어 미로 게임을 2명이 동시에 플레이할 수 있습니다. 재배포는 `npm run deploy`, Workers 로컬 실행은 `npm run worker:dev`입니다. 자세한 내용은 [WORKERS.md](WORKERS.md)를 참고하세요.

기본 게임을 `test_coding`의 파이썬 게임을 참고한 **내비게이터·익스플로러 두 시점의 미로 게임**으로 개편했습니다. `npm run dev` 실행 후 `http://localhost:5173`에서 바로 플레이할 수 있습니다. 역할별/CPU 모드, 벽과 비밀 통로, HP와 물고기 도감, 미로·시간·벽·이동 간격 설정을 지원합니다. 점수 제도는 없습니다.

魚に触れるとエクスプローラーの種類別図鑑が埋まり、実際に出た生物のリスクに応じてナビゲーターのHP（💛30）が減ります。図鑑は大サイズ3列・中サイズ4列・小サイズ5列とし、大サイズの画像を大きく表示します。未発見は暗いシルエットと「？？？」、発見後はカラー画像と名前を表示します。同じ種類への再接触で図鑑の種類数は増えません。結果の「出会い」は種類数ではなく接触した場所の数です。シルエットの ! / !! / !!! は最大リスクで、同じサイズ・表示リスク以下の生物からランダムに選ばれます。低リスク2・中リスク3・高リスク4で、全12か所の魚に触れるとHPが0になる場合もあります。壁の設置成功時にもHPを2消費します（設置失敗時は消費なし）。壁は初期10枚です。HPは0未満にはならず、0でも時間までプレイと壁の設置を続けられます。図鑑とHPはラウンドごとにリセットします。生物は元の詳細なイラストの青い背景を透過処理した12種類のPNGを使用し、接触前の光るシルエットは維持しています。

새 미로도 **두 사람이 각자 브라우저에서 동시에 플레이**할 수 있습니다. 화면 위에서 방을 만들고 초대 링크 또는 코드를 공유한 뒤, 두 사람 모두 준비 완료를 누르세요. 부모는 벽을 설치하고 아이는 이동하며, 역할별 화면과 비밀 통로가 분리됩니다. 방에 들어가지 않으면 CPU와 혼자 연습할 수 있습니다.

새 게임의 조작법과 검증 방법은 [MAZE.md](MAZE.md)를 참고하세요. 바다 도입부, 다이버와 수중 효과의 구현 및 검증 안내는 [OCEAN.md](OCEAN.md)에 있습니다.
